SMAINER — START HERE

Smainer is a decentralized compute marketplace on Starknet.
Users submit tasks, providers execute them, payments settle on-chain in STRK.

REPOSITORY STRUCTURE

  contracts/     Cairo smart contracts (escrow, fees, task lifecycle)
  backend/
    relayer/     FastAPI coordination service (WebSocket, Redis, scheduling)
    provider/    Python daemon for GPU providers (sandbox, signing, metrics)
    ai-compute-node/  Ollama AI inference integration
  frontend/      Next.js dashboard (wallet connect, task submit, provider stats)
  telegram/
    telegram-bot/   Telegram bot (pay-per-prompt AI, STRK payments)
    miniapp/        Telegram Mini App (wallet connect UI)
  desktop/       Windows desktop node app (Tauri, GPU detection, onboarding)
  docs/          All documentation (architecture, operations, security, economics)
  deployment/    Docker, systemd, infrastructure configs
  monitoring/    Health checks, metrics collection
  scripts/       Operational scripts
